Passo a Passo para Conclusão da Tarefa
1. Criei um novo repositório público no GitHub com a ramificação principal definida como `main`.
2. Fiz o upload dos arquivos e documentos referentes ao projeto diretamente pelo navegador no GitHub.
3. Criei o arquivo `README.md` contendo as informações de identificação, descrição e resumo das etapas que concluí.
4. Confirmei as alterações (*Commit*) e copiei o link do repositório para entregar a atividade na plataforma Microsoft Teams.
